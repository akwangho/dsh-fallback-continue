# dsh-fallback-continue

當對話因紅字「本輪運行失敗」(turn error) 而終止時，這個外掛會自動替**那個會話**排程送出「繼續」，以遞增的間隔無限重試，直到你接手或取消。

> 這是一個「動態 Cordis 外掛」：以 `code.host` + `code.client` 兩段純 JavaScript 函式本體定義，透過 `cordis_define` / `cordis_run` 載入目前這個 DSH 程序。重啟 `dsh web` 後需要重新跑一次 `cordis_run`（動態外掛不跨程序留存）。

## 功能

- **自動繼續**：偵測到會話 run failure 後，第一次重試在失敗後 **5 分鐘**（不是立刻），之後間隔依 `5 → 10 → 15 → 30 → 60 → 60 → 60 → 60` 分鐘遞增，接著永遠 60 分鐘，無限循環。
- **觸發**：簡中／繁中／英文介面的紅字都一樣，因為判斷依據是 Host 的 `agent/error` 事件與 `turn/end` 的 `error` / `max-tokens` 結束原因，而非前端字串。
- **開關**：設定頁「失敗自動繼續」卡片可開／關；關閉等於沒裝（不會排程任何重試）。
- **倒數顯示（只看當前會話）**：畫面右下角浮動顯示目前正在看的會話那一條倒數，每秒更新；切到別的會話就隱藏。
- **手動控制**：點倒數文字＝暫停／繼續；點 ✕＝取消。設定卡內有完整等待清單（倒數、第幾次、失敗原因、暫停／立即重試／取消）。
- **停止條件**：你手動送出任何訊息、重試成功、按取消／暫停、會話被 archive、超過上限時數（預設 24h，`0`＝無上限）、或外掛被關閉。

## 可設定項目

| 項目 | 說明 | 預設 |
| --- | --- | --- |
| 啟用 | 總開關 | 關 |
| 自動送出的文字 | 每次送給大模型的文字 | 繼續 |
| 重試間隔（分鐘） | 逗號分隔，用完重複最後一個 | `5,10,15,30,60,60,60,60` |
| 超過上限自動停止 | 啟用 24h 這類上限 | 開 |
| 上限時數 | 從第一次失敗起算，`0`＝無上限 | 24 |

## 檔案結構

- `config.json` — 名稱、版本與預設值。
- `README.md` — 本文件。
- `src/host.js` — Host 半部：失敗偵測、倒數 timer、送「繼續」、停止條件、RPC。
- `src/client.js` — Client 半部：設定卡、右下角倒數、等待清單。

## 注意事項

- 重啟 DSH 程序後，等待中的倒數會重來（狀態只在記憶體，不跨程序留存）。
- 有些失敗是確定性的（例如模型不支援那麼大的 token 數），重試永遠不會成功——這種請手動處理（換模型或調參數），不要等自動繼續。
- 更新程式後需重啟 `dsh web` 才會生效。
